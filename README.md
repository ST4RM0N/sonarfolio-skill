# Sonarfolio Skill

Portfolio layer for NEXUS Prime — stocks, ETFs, crypto via LunarCrush Sonar.

Seven tools over MCP, REST, and CLI: usage, held assets, asset lookup, asset search, portfolio summary, holdings list, and one descriptive write (`add_position`).

## Install

Copy this directory to your Grok skills path as `sonarfolio`.

MCP endpoint: https://sonarfolio.com/api/mcp
REST base: https://sonarfolio.com/api/v1/
CLI: `npm i -g sonarfolio` (Node 18+)

Auth: API key as bearer token, or OAuth for Claude/ChatGPT MCP clients.
